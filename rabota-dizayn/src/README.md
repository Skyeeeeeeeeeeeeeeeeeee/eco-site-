# ЭКО СЕРВИС НОВОСИБИРСК: два сайта из одного исходника (темы E и F)

Фотографии на сайтах иллюстративные (стоковые, Wikimedia Commons): их нужно заменить снимками компании. Авторы и условия использования выводятся под каждым фото и списком на странице «О компании» (раздел «Источники фото»), список строится из `shared/photos/credits.json`.

## Команда

```
node rabota-dizayn/src/tools/build.mjs                 # собрать оба сайта и страницу выбора rabota-dizayn/index.html
node rabota-dizayn/src/tools/build.mjs --theme=e       # только одну тему (e | f)
node rabota-dizayn/src/tools/build.mjs --production    # падает, пока в content.js остались «ЗАГЛУШКА»; метки не выводятся
```

Нужен только Node 18+. Сборка пересоздаёт папки `e-svetlo-goluboy/` и `f-vozdushnyy/` целиком, поэтому правьте только `src/` и `shared/`. После сборки автоматически проверяются: title ≤60, description ≤160, один H1, ссылки и якоря (page-relative, с `index.html`), JSON-LD, внешние ресурсы, подписи и размеры фото, три.js только на страницах с 3D, примеры калькулятора (13 400 и 104 850 ₽).

## Состав

| Путь | Что это |
|---|---|
| `src/js/content.js` | Единственный источник данных (тексты, ставки, модели, отзывы, FAQ, фото). Заглушки помечены `// ЗАГЛУШКА`. Авторы фото подставляются из `credits.json` |
| `src/js/calc.js`, `main.js` | Ядро калькулятора (как в v2), интерактив: меню с ловушкой фокуса, формы, маска телефона, калькулятор, вкладки, фильтр, карусель отзывов |
| `src/js/cabin-init.js` | Монтирует 3D-кабину в `[data-cabin3d]`, пресет по `<html data-theme>` |
| `src/templates/` | `lib.mjs` (компоненты), `pages.mjs` (страницы), `layout.mjs` (head, шапка, подвал) |
| `src/css/main.css` | Вся вёрстка на токенах (Onest, пилюли, панели, bento, процесс, карусель, FAQ) |
| `src/css/themes.css` | Темы: два набора токенов `[data-theme="e"]` и `[data-theme="f"]` и малые отличия |
| `src/fonts/` | Onest woff2 (cyrillic, latin, символ ₽), метрически подогнанный запасной шрифт в `main.css` |
| `src/img/` | Иконки и плоские кабины (встраиваются в каждую страницу), favicon, og.svg |
| `shared/cabin3d/`, `shared/photos/` | 3D-модель и фото (копируются в каждый сайт при сборке) |

## Как устроены темы

Разметка у обеих тем одна. Тема E: голубая шапка и герой, тёмно-синие блоки (карточки bento, расчёт, отзывы, бегущая строка, подвал). Тема F: всё светлое, те же блоки белые или бледно-голубые с тонкой рамкой. Различия только в `themes.css`. Новую тему делают копированием блока токенов.

## Заметки

- Сайты открываются двойным кликом (file://): ссылки относительные и с `index.html`, спрайт встроен в страницу, шрифты грузятся из CSS, нет preload с crossorigin, нет ES-модулей, нет fetch/XHR. Формы ничего не отправляют.
- 3D: `three.min.js`, `cabin3d.js`, `cabin3d.css` подключаются только на главной и страницах моделей ЭС-01, ЭС-02, ЭС-04. На остальных страницах их нет. При `prefers-reduced-motion` авто-вращение выключено, при отсутствии WebGL остаётся плоская SVG внутри контейнера.
- Одна и та же 3D-кабина показана на страницах ЭС-02 и ЭС-04, подпись это оговаривает; особенности моделей показаны на схеме и в характеристиках. На странице ЭС-03 главное изображение: фото, схема рядом.
- Плашка cookie не используется (не перекрывать экран, не сдвигать вёрстку).
