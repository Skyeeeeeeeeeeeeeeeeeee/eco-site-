# Cabin3D — реалистичная 3D-модель туалетной кабины

Процедурная модель ротоформованной кабины (≈1.12 × 1.17 × 2.30 м): скруглённые рёбра, рельефные панели, купольная белая крыша, дверь с жалюзи, ручкой, индикатором «свободно/занято», петлями, пиктограммой, вентиляционной трубой, базой-салазками с карманами под погрузчик. Все текстуры (normal/roughness, наклейки, окружение) генерируются на canvas в рантайме — внешние файлы не нужны, работает через `file://`.

## Подключение

```html
<link rel="stylesheet" href="shared/cabin3d/cabin3d.css">
<div id="cabin" style="height:460px">
  <img src="fallback.png" alt="Туалетная кабина">  <!-- запасной контент, если нет WebGL -->
</div>
<script src="shared/cabin3d/vendor/three.min.js"></script>
<script src="shared/cabin3d/cabin3d.js"></script>
<script>
  var cabin = Cabin3D.mount(document.getElementById('cabin'), {
    colors: Cabin3D.PRESET_E,
    autoRotate: true,
    initialAngle: 30,
    quality: 'high',      // 'high' | 'low' (по умолчанию авто)
    roof: 'white',        // 'white' | 'tinted' (по умолчанию — colors.roof)
    occupied: false,      // true — окно «ЗАНЯТО» (красное)
    onReady: function (api) {}
  });
</script>
```

## Опции

| Опция | Описание |
|---|---|
| `colors` | `{body, side, roof, door, accents, base, indicator}` — HEX-цвета; недостающие берутся из PRESET_E |
| `autoRotate` | автовращение (отключается при `prefers-reduced-motion`) |
| `initialAngle` | начальный угол, градусы |
| `quality` | `'high'` / `'low'`; авто: `low`, если `innerWidth < 600` или `devicePixelRatio > 2` |
| `roof` | `'white'` — всегда белая; `'tinted'` — белая с оттенком цвета корпуса; не задано — `colors.roof` |
| `occupied` | индикатор на двери «ЗАНЯТО» вместо «СВОБОДНО» |
| `onReady(api)` | вызывается после первого кадра |
| `model` | вариант модели, см. ниже; по умолчанию `'standart'` |
| `scene` | `'studio'` (по умолчанию) или `'outdoor'` |
| `count` | только для `scene:'outdoor'`: 1–3 кабины в ряд |
| `colorsList` | массив `colors` для каждой кабины ряда (индекс 0 — главная) |
| `drift` | `true` — очень медленный дрейф камеры на несколько градусов (outdoor и не только) |
| `scrollRotate` | `true` — дополнительный поворот до ±25° по положению блока в окне |
| `elevation` | угол камеры над горизонтом, градусы (по умолчанию 9; в outdoor 11) |
| `frost` | только `uteplennaya`: изморозь на кромке крыши (по умолчанию `true`, `false` — выкл.) |
| `shadow` | `'soft'` — мягкая контактная тень вместо длинной солнечной (для каталожных рендеров, студия) |
| `static` | `true` — отрисовать один кадр без rAF-цикла (для скриншотов) |

Возвращает `{destroy, getAngle, setAngle, getTilt, ready, webgl, model, scene}` (+ `quality`, `info.triangles`, в outdoor ещё `info.sceneTriangles`).

Все новые опции необязательны. Вызов `mount()` без них даёт ровно прежнюю картинку и поведение (проверено попиксельно).

## Варианты модели (`model`)

| Значение | Что это |
|---|---|
| `'standart'` | текущая кабина (по умолчанию) |
| `'rukomojnik'` | та же кабина + настенный пластиковый рукомойник с ножной педалью (подсказка «↓ НАЖМИ») и дозатор мыла на левой стене |
| `'malomobilnye'` | доступная кабина ≈ 2.2 × 1.65 × 2.3 м, дверь 0.9 м приоткрыта (внутри поручни, унитаз), пандус с противоскользящим рифлением, поручни пандуса, табличка ISA на двери |
| `'uteplennaya'` | утеплённая зимняя: толще стены, плоская крыша, швы сэндвич-панелей, решётка обогрева, палитра страницы; на кромке крыши лёгкая изморозь (canvas-текстура) |
| `'torfyanoj'` | дачный торфяной туалет (изделие ≈ 0.45 × 0.6 × 0.75 м): тумба с сиденьем и приоткрытой крышкой, бак для торфа с рычагом, ведро с торфом и совок |

Палитра `colors` действует на все модели. Камера подбирается под габариты модели автоматически.

## Сцена `outdoor`

```js
Cabin3D.mount(el, { scene: 'outdoor', count: 3, drift: true, autoRotate: false,
  colors: Cabin3D.PRESET_E, colorsList: [Cabin3D.PRESET_E, Cabin3D.PRESET_F, Cabin3D.PRESET_CLASSIC] });
```

- Земля: диск с процедурной текстурой мелкого гравия, переходящего к краям в короткую траву, с normal-картой; по краю затухает в прозрачность (alpha-карта), так что стоит на фоне страницы без шва.
- Свет: небесная полусфера + тёплое солнце с мягкими тенями; окружение для отражений собрано из градиентной «небесной» сцены (PMREM).
- `count: 3`: главная кабина спереди, две позади и сбоку со смещением. Фоновые кабины строятся упрощённой сеткой, поэтому бюджет ≈ 74 тыс. треугольников (high); при `quality:'low'` — ≈ 40 тыс. Если бюджет 86 тыс. превышен (тяжёлые модели), главная кабина автоматически упрощается.
- `drift: true` — камера плавно «дышит» ±5° по азимуту; отключается при `prefers-reduced-motion`.
- Начальная генерация текстуры земли занимает порядка 100–300 мс (в `low` текстура 1024 вместо 2048 px).

## scrollRotate

`scrollRotate: true` добавляет к повороту по Y до ±25° в зависимости от положения блока в окне (центр блока выше центра окна — «плюс»), по S-образной кривой с сглаживанием. Пассивный `scroll`-слушатель + расчёт в rAF; при `prefers-reduced-motion` выключено.

## Статические рендеры для каталога

`node tools/render.mjs [--only=standart|rukomojnik|malomobilnye|uteplennaya|torfyanoj] [--palette=e|f]` — Playwright + Chromium (swiftshader). Страница `tools/render.html` рендерит модель на 1200×1200 при deviceScaleFactor 2 (холст 2400², студия, 3/4, мягкая тень, прозрачный фон), кадр берётся через `page.screenshot({omitBackground:true})` (без `preserveDrawingBuffer`), затем `tools/post.py` (Pillow) уменьшает до 900 и 450 px и держит 900-px PNG < 400 КБ (при необходимости снижает разрядность RGB, альфа остаётся 8-бит; если есть pngquant — использует его).

Результат: `rabota-dizayn/shared/renders/{model}-{e|f}.png` и `{model}-{e|f}-450.png`. Путь к playwright можно задать переменной `CABIN_PW`.

## Пресеты

`Cabin3D.PRESET_E` (голубой #6FA6DB), `Cabin3D.PRESET_F` (светлый #8DBCEB), `Cabin3D.PRESET_CLASSIC` (насыщенный синий #1F5FAF); общий список — `Cabin3D.PRESETS`. У всех белая полупрозрачная крыша, тёмная база #2B3A4A, дверь на тон темнее.

## Режимы качества

- `high`: тени 2048, плотные сетки, pixelRatio до 2, ≈56 тыс. треугольников (standart; rukomojnik ≈65, malomobilnye ≈74, uteplennaya ≈35, torfyanoj ≈12 тыс.).
- `low`: тени 1024, упрощённые сетки и текстуры 128 px, pixelRatio до 1.25, ≈20 тыс. треугольников (standart).

Управление: перетаскивание, стрелки ← → при фокусе. Рендер ставится на паузу, когда блок вне экрана или вкладка скрыта. Если WebGL недоступен — остаётся запасной контент внутри контейнера.
