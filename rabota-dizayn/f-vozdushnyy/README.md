# ЭКО СЕРВИС НОВОСИБИРСК: тема F «Воздушный»

Готовый сайт, открывайте `index.html` двойным кликом, сервер не нужен. Не правьте файлы здесь: они создаются командой `node rabota-dizayn/src/tools/build.mjs` из `rabota-dizayn/src/`.

Фотографии иллюстративные (стоковые, Wikimedia Commons), их нужно заменить снимками компании. Авторы и условия использования: страница «О компании», раздел «Источники фото».
