# ЭКО СЕРВИС НОВОСИБИРСК: вариант 2 (многостраничный сайт)

Статический сайт: чистый HTML, CSS и JS без фреймворков и npm-зависимостей. Готовые страницы лежат в этой папке (`index.html`, `arenda/index.html`, `katalog/standart/index.html` и т.д., `404.html`, `sitemap.xml`, `robots.txt`). Вариант 1 (одностраничник в корне репозитория) не затрагивается.

## Структура

| Путь | Что это |
|---|---|
| `js/content.js` | **Единственный источник данных**: компания, контакты, ставки, зоны, модели, отзывы, FAQ, формы, SEO страниц. Каждая заглушка помечена `// ЗАГЛУШКА`. Цены моделей не хранятся, а считаются как ставка × коэффициент |
| `js/calc.js` | Формулы калькулятора и расчёта количества кабин (общие для браузера и сборки) |
| `js/main.js` | Интерактив: меню, формы, маска телефона, калькулятор, вкладки, фильтр каталога |
| `src/lib.mjs`, `src/pages.mjs`, `src/layout.mjs` | Шаблоны: компоненты, тексты страниц, шапка/подвал/head |
| `tools/build.mjs` | Генератор и проверки (только Node 18+) |
| `tools/make-sprite.mjs` | Пересборка `img/sprite.svg` (иконки и изометрические схемы кабин) |
| `css/main.css`, `fonts/`, `img/` | Стили, шрифты IBM Plex (woff2, свои), спрайт |

## Команды (из папки `v2/`)

```
node tools/build.mjs                 # собрать все страницы (dev: метки «Заглушка» видны)
node tools/build.mjs --check         # проверка без записи: title ≤60, description ≤160, один H1,
                                     # битые ссылки и якоря, JSON-LD, примеры калькулятора (13 400 и 104 850 ₽),
                                     # актуальность файлов на диске
node tools/build.mjs --production    # то же, но падает, пока в content.js остались «ЗАГЛУШКА»; метки не выводятся
node tools/build.mjs --base=/v2      # если сайт лежит не в корне домена (ссылки получат префикс)
python3 -m http.server 8000          # предпросмотр: открыть http://localhost:8000/ (папка v2/ как корень сайта)
```

## Как править данные

1. Откройте `js/content.js`, замените значения (контакты, ставки, модели, отзывы, FAQ, домен `site.domain`).
2. Уберите комментарии `// ЗАГЛУШКА` у значений, подтверждённых клиентом.
3. Запустите `node tools/build.mjs`, затем `node tools/build.mjs --check`.
4. Перед запуском сайта: `node tools/build.mjs --production`. Команда покажет, что ещё не заменено.

Тексты страниц и структура блоков лежат в `src/pages.mjs`; числа и сроки в них берутся из `content.js`. Ссылки строятся по путям и `slug` из данных.

## Что нужно знать

- Формы ничего не отправляют (нет fetch/XHR): показывают состояние успеха на месте. Подключение CRM или почты делается в `js/main.js` (обработчик `submit`).
- Без JS формы и калькулятор скрыты, вместо них показан телефон; FAQ, таблицы и характеристики читаются полностью.
- Файл образца договора не создан: в `content.js` у документа `file: null`, на странице показана кнопка «Скоро».
- `img/og.svg` нужно заменить растровым 1200×630 (соцсети не читают SVG).
- Сервер должен отдавать `404.html` со статусом 404 для неизвестных адресов.

## Копия для просмотра без сервера

`node tools/export-static.mjs ../designs/02-site-grafit-laym` — собирает сайт и кладёт в указанную папку версию с относительными путями, которая открывается двойным кликом по `index.html`.
