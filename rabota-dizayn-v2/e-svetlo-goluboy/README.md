# ЭКО СЕРВИС НОВОСИБИРСК, версия 2: тема Е «Светло-голубой»

Готовый сайт, открывайте `index.html` двойным кликом, сервер не нужен. Не правьте файлы здесь: они создаются командой `node rabota-dizayn-v2/src/tools/build.mjs` из `rabota-dizayn-v2/src/` и общих ресурсов `rabota-dizayn/shared/`.

Фотографии иллюстративные (стоковые, Wikimedia Commons), их нужно заменить снимками компании. Авторы и условия использования: страница «О компании», раздел «Источники фото».
