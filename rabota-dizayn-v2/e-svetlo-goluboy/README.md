# ЭКО СЕРВИС НОВОСИБИРСК, версия 2: тема Е «Светло-голубой»

Готовый сайт, открывайте `index.html` двойным кликом, сервер не нужен. Варианты первого экрана главной: `index-a.html`, `index-b.html`, `index-c.html` (`index.html` = вариант A). Не правьте файлы здесь: они создаются командой `node rabota-dizayn-v2/src/tools/build.mjs` из `rabota-dizayn-v2/src/` и фото `rabota-dizayn/shared/photos/`.

Фотографии иллюстративные (стоковые, Wikimedia Commons), их нужно заменить снимками компании. Авторы и условия использования: страница «О компании», раздел «Источники фото».
