# ЭКО СЕРВИС НОВОСИБИРСК: два сайта из одного исходника (темы E и F)

Фотографии на сайтах иллюстративные (стоковые, Wikimedia Commons): их нужно заменить снимками компании. Авторы и условия использования выводятся под каждым фото и списком на странице «О компании» (раздел «Источники фото»), список строится из `rabota-dizayn/shared/photos/credits.json` (только чтение; v1 и `shared/` не меняются).

## Команда

```
node rabota-dizayn-v2/src/tools/build.mjs                 # собрать оба сайта и страницу выбора rabota-dizayn-v2/index.html
node rabota-dizayn-v2/src/tools/build.mjs --theme=e       # только одну тему (e | f)
node rabota-dizayn-v2/src/tools/build.mjs --production    # падает, пока в content.js остались «ЗАГЛУШКА»; метки не выводятся
```

Нужен только Node 18+. Сборка пересоздаёт папки `e-svetlo-goluboy/` и `f-vozdushnyy/` целиком, поэтому правьте только `src/`. После сборки автоматически проверяются: title ≤60, description ≤160, один H1, ссылки и якоря (page-relative, с `index.html`), JSON-LD, внешние ресурсы, подписи и размеры фото, отсутствие 3D и снятых моделей, три варианта главной, примеры калькулятора.

## Ассортимент (решение клиента)

МТК = мобильная туалетная кабина. Аренда для строек (длительно): МТК Стандарт. Аренда на мероприятия (на сутки): МТК Комфорт, МТК VIP (Комфорт + рукомойник и зеркало). Продажа: МТК Стандарт, МТК Эконом. Страницы: `/katalog/mtk-standart/`, `mtk-ekonom/`, `mtk-komfort/`, `mtk-vip/`. Характеристики и цены в `content.js` помечены «ЗАГЛУШКА».

Схема цен: Стандарт считается по ступеням срока (`rates.rentPerDay`), Комфорт и VIP: фиксированная цена за кабину за сутки (`models[].rent.perDay`), доставка и визит обслуживания считаются отдельно. В одну машину помещается до 20 кабин (`rates.delivery.cabinsPerTrip`, факт клиента). Часы работы: Пн–Пт 09:00–17:00, Сб–Вс выходной (факт клиента).

Эталонные примеры калькулятора (проверяются при сборке): 2 Стандарта на 10 суток с обслуживанием раз в неделю в городе = 13 400 ₽; мероприятие на 300 гостей, 4–8 часов, с алкоголем, одни сутки: 11 кабин (8 Комфорт и 3 VIP), аренда 31 700 − скидка 10% (3 170) + доставка 800 (один рейс) = 29 350 ₽.

## Главная: три варианта первого экрана

Собираются `index-a.html` («Фото»), `index-b.html` («Линейка моделей» с переключателем Аренда / Купить), `index-c.html` («Какая задача?»). `index.html` = копия варианта A. Всё ниже первого экрана общее. В dev-сборке над героем есть переключатель вариантов (в `--production` его нет). Выбранный вариант остаётся единственным: остальные файлы и функции `heroA/B/C` в `templates/pages.mjs` удаляются. Превью для страницы выбора: `previews/{e|f}-{a|b|c}.jpg`.

## Состав

| Путь | Что это |
|---|---|
| `src/js/content.js` | Единственный источник данных (тексты, ставки, модели, отзывы, FAQ, фото). Заглушки помечены `// ЗАГЛУШКА` |
| `src/js/calc.js`, `main.js`, `life.js` | Ядро калькулятора и расчёта мероприятий, интерактив, живой виджет приёма заявок (рабочие дни и часы из `SITE.copy`) |
| `src/templates/` | `lib.mjs` (компоненты), `pages.mjs` (страницы), `layout.mjs` (head, шапка, подвал) |
| `src/css/main.css`, `themes.css` | Вёрстка на токенах и две темы |
| `src/img/cabins.svg.frag` | Плоские SVG моделей (`mS`, `mE`, `mK`, `mV`, `mVin`), встраиваются в каждую страницу |
| `src/fonts/` | Onest woff2 |

## Заметки

- Сайты открываются двойным кликом (file://): ссылки относительные и с `index.html`, спрайт встроен, нет ES-модулей, fetch/XHR, preload с crossorigin. Формы ничего не отправляют.
- 3D (three.js, cabin3d) убрано полностью: изображения моделей плоские SVG, фото копируются только используемые.
- Плашка cookie не используется.
