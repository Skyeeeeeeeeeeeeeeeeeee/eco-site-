# Варианты дизайна

Все готовые варианты дизайна сайта «ЭКО СЕРВИС НОВОСИБИРСК» в одной папке. Оглавление с превью — `index.html`.

| Папка / файл | Что это |
|---|---|
| `01-site-siren-mandarin/` | Сайт 1 «Сирень и мандарин» — яркий одностраничник (копия сайта из корня репозитория) |
| `02-site-grafit-laym/` | Сайт 2 «Графит и сигнальный лайм» — строгий многостраничный сайт, 20 страниц (экспорт `v2/` для открытия с диска) |
| `03-first-screens/` | Три концепции первого экрана: «Объявление», «Цена крупно», «Свободно» |
| `04-home-pages/` | Три главные страницы по референсам: A — Devialet, B — marketpartners.org, C — luxorr.io |
| `previews/` | Скриншоты первых экранов для оглавления |

## Как открыть

Все варианты открываются двойным кликом по HTML-файлу, сервер не нужен. Начните с `index.html` — это оглавление.

## Важно

- Это снимки для сравнения. Разработка ведётся в исходниках: сайт 1 — в корне репозитория (`index.html`, `css/`, `js/`), сайт 2 — в `v2/` (данные в `v2/js/content.js`, сборка `node tools/build.mjs`).
- Сайт 2 здесь — экспорт для открытия с диска (относительные пути, встроенный спрайт иконок). Не правьте его вручную: меняйте `v2/` и обновляйте копию командой `cd v2 && node tools/export-static.mjs ../designs/02-site-grafit-laym`.
- Шрифты в `03-…` и `04-…` подгружаются с Google Fonts, без интернета будет системный шрифт. В сайтах 1 и 2 шрифты лежат локально.
- Цены, контакты, отзывы и цифры — заглушки.
